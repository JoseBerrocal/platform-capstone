# AWS Evidence

This folder contains validation evidence for the AWS EKS deployment of the platform capstone.

Validated components:

- EKS nodes
- ArgoCD applications
- ingress-nginx
- Application ingress
- Grafana ingress
- Prometheus ingress
- Metrics Server
- Pod and node metrics
- CloudNativePG PostgreSQL HA
- Reliability and observability validation
- Prometheus alerting
- Deployment degradation detection
- Incident recovery validation
